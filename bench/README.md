# Benchmark Suite

Benchmarking system with modularisation between sweep generation, data structures and sweep execution.

## Structure

### Modules
- `benchmark.py` - Data structures and CSV IO
- `sweep.py` - Parameter sweep runner for batch benchmarking
- `generate_cluster_sweeps.py` - Parameter sweep runner for batch benchmarking

## Usage
### Generate Sweep with `generate_cluster_sweeps.py`
Parameters:
- `sweep_type`, available:
  - density
  - pe-scaling
  - constant-nnz
  - weak-scaling
  - memory-util
  - load-balance
  - large-scale
  - comprehensive

Common parameters
- `--rows`, default: 10000
- `--cols`, default: 10000
- `--density`, default: 0.01
- `--num-pes`, default: 512
- `--output-dir`, default: `bench/configs/cluster`
For own testing purposes we always 

Sweep-specific parameters:
- `--num-points`, default: 50, number of points in sweep
- `--density-min`, default: 0.001, min sweep density
- `--density-max`, defaultI: 0,1, max sweep density

### `benchmark.py`
Datastructure to manage benchmark results, includes save/load benchmark operations to work on them.

### `sweep.py`
Runs the config files generated by `generate_cluster_sweeps.py`.

Parameters:
- `--config` file to run
- `--results`, save location, default: `results/data/$(date -I)_[config_name].csv`
- `--run-script`, script to run with, default: `run.py`
- `--continue-on-error`, if to continue running the script in case of a run breaking, default: true.
- `--verbose`, if to enable debug logging.
